  Both MEASURED terms are ORDER STATISTICS over the link set, so both are
  non-decreasing in N by construction -- adding a link can only widen the owd
  spread and can only raise max(jit).  That much is N-generic in FORM.
  What is not: the +130 ms is the LARGEST term at every N in the table, so the
  hold is majority-constant everywhere the rig has ever run.
  WIDEST mix the archetype set can build (all five, any N>=5): raw=249.0 ms,
  ceiling=350 ms.  The ceiling is UNREACHABLE with these archetypes at ANY N --
  max/min are set by the archetype SET, not by how many links are drawn from it,
  so duplicating links cannot widen it.  Nothing in the rig ever exercises either
  clamp: they are untested code at every N the battery runs.
