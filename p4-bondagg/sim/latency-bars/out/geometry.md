A bar id is GATED only when EVERY one of its checks kept the same verdict
on every geometry. One flip anywhere in the id demotes the whole id: the
gate classifies by id, so a mixed id would gate a coin flip under another
check's name.

surviving bar is stable -- only that it did not flip on these draws. U33's
own conclusion applies unchanged: the geometry axis is sampled by PHASE
ONLY; stall COUNT and DURATION remain the hand-placed canonical values, so
this is a lower bound on the true spread.
