Datapath (read-only)

  

  

  
One click is one p5-reconciler _stats, which reads the
     file the datapath renames into place on its own tick. The page has no timer:
     the age shown is computed on the box from the file's own ts=,
     never from this browser's clock, and fresh/stale comes from the cadence the
     file states in ival_ms= rather than from a number kept here.
     Throughput is a delta between two reads, so the first read has none.
     Delivery-latency percentiles are not measured by the datapath and print
     absent; a zero there would be a fabricated number.
